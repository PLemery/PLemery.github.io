Academic Performance App & Grade Tracker

A native iOS app that syncs grades from Canvas LMS, calculates each course grade exactly as Canvas does, and helps students plan with what-if scores, target grades, and GPA projection.

Project Overview

The Academic Performance App pulls courses, assignment groups, assignments, and scores from the Canvas REST API and computes each course grade with the same rules Canvas uses, including group weights, drop rules, and extra credit. Students then layer their own plans on top: what-if scores, target grades, credit hours, and assignments Canvas doesn't know about yet.

The app has no accounts and no server. It talks only to Canvas, stores user edits on device with SwiftData, and syncs them across devices through iCloud. Started in July 2025, the app was rebuilt in Swift 6 around a pure, fully tested grade engine.

Key Features

Canvas Sync

Connect a Canvas access token and pick a school from a searchable university picker. Courses, assignment groups, weights, drop rules, grading standards, and class score statistics sync automatically.

Canvas-Accurate Grades

Handles weighted groups, total-points courses, drop-lowest and drop-highest rules with never-drop exceptions, and extra credit, so the grade in the app matches the grade in Canvas.

What-If & Target Grades

Enter what-if scores on any assignment, add manual assignments for upcoming work, and see the lowest score needed on remaining work to reach a target grade.

Scenarios & GPA Projection

Projects the final grade if every remaining assignment scores a given percent, and projects GPA from each course's grade and credit hours.

Effort Analysis

Ranks assignments by impact, meaning how many points the course grade would move between 0% and 100% on that assignment, so students know where to focus.

Offline & iCloud Sync

The last Canvas fetch is cached on disk so courses appear instantly, even offline. User edits sync across devices through SwiftData and CloudKit.

Technical Implementation

Grade Engine (GradeCore Swift Package)

Swift 6 Swift Package Manager Swift Testing
  • Pure Grade Engine: A single function computes every grade from a Canvas snapshot and the user's overlay, with no UI or networking code involved
  • Score Policies: One grading routine serves current grades, what-if grades, and scenario projections by swapping the policy that decides how many points each assignment counts for
  • Testing: 66 unit tests, including regression tests that replay recorded responses from a real Canvas account

Canvas Integration

Canvas LMS API REST APIs Swift Concurrency
  • Canvas Client: Token-authenticated REST requests that follow Canvas's pagination headers
  • Concurrent Fetching: Fetches courses in parallel, four at a time, with per-course error isolation so one failing course keeps its cached data instead of breaking the sync
  • Secure Storage: The Canvas token is stored in the iOS Keychain, never in plaintext

App & Storage

SwiftUI SwiftData CloudKit Keychain
  • Single Source of Truth: An observable store owns all graded courses, and views only read results, never compute grades
  • Overlay Storage: User edits are saved with SwiftData and synced through CloudKit, with backward-compatible decoding so data saved by older versions still loads
  • No Backend: No accounts, servers, or databases to run; the app talks only to Canvas

How It Works

1. Connect Canvas

On first launch, students pick their school and paste a Canvas access token in Settings. The token is saved to the Keychain.

2. Instant Startup

On launch, the app loads the last Canvas fetch from disk and the user's saved edits from SwiftData, grades every course, and shows results right away. It then refreshes from Canvas in the background.

3. Two Data Models

Each course has a read-only snapshot of what Canvas returned and a separate overlay of what the student added:

  • Target grade and credit hours
  • What-if scores
  • Manual groups and assignments
  • Manual weight overrides for courses that use total points in Canvas but weights in the syllabus

A Canvas refresh replaces only snapshots, so syncing never overwrites a student's edits.

4. Grading & Planning

The grade engine merges each snapshot with its overlay, picks the course's weighting mode, applies drop rules, and returns current and what-if grades, letter grades, per-group percents, and each assignment's impact. The Simulator and Analysis tabs build on those results.

Challenges & Solutions

Challenge 1: Matching Canvas Exactly

Problem: A grade tracker is only useful if it matches the official grade, and Canvas combines weights, drop rules, excused and missing work, and extra credit in specific ways.

Solution: Isolated all grade math in a pure, fully tested engine and added regression tests that replay real Canvas data, so every rule is checked against what Canvas actually reports.

Challenge 2: Syncing Without Losing Edits

Problem: Re-downloading Canvas data could wipe out a student's what-if scores and manual assignments.

Solution: Separated Canvas data from user edits into two models. Syncs replace only the Canvas snapshot, and the engine combines both every time it grades.

Challenge 3: Reliable Sync Across Many Courses

Problem: Fetching each course one at a time is slow, and a single failing request could break the whole refresh.

Solution: Fetched courses concurrently with per-course error isolation and an on-disk cache, so the app starts instantly, works offline, and keeps showing cached data for any course that fails.

Challenge 4: CloudKit Storage Constraints

Problem: SwiftData with CloudKit requires a default for every property and doesn't allow unique constraints, which made the user's edits hard to model directly.

Solution: Stored each course's overlay as an encoded record with custom decoding that fills in defaults, so data from older app versions still loads.
